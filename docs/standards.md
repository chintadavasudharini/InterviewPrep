# Python OOP Curriculum: Standard Commands

| Command | What it does |
| --- | --- |
| **"Standardize Spacing"** | Removes gaps after headings; adds a single-line gap between topics. |
| **"Apply Revision Questions"** | Adds the 🔹 1. Question format with compact answers at the end. |
| **"Add Quick Revision"** | Adds the summary bullet-point table at the bottom of the page. |
| **"Use Diamond Bullets"** | Uses 🔹 for all interview questions and accordion headers. |
| **"Use Period Bullets"** | Uses . for all explanation and step-by-step bullet points. |
| **"Set Core Concept"** | Uses "Core Concept:" as the main label for the initial definition. |
| **"Compact Q&A"** | Ensures no space between a Q and its A, but a gap between different Q&As. |
| **"Full Topic Standardization"** | Applies ALL of the above to a specific page or the whole curriculum. |

## Visual Reference Guide
When "Full Topic Standardization" is requested, ensure the page follows this format:

**[TOPIC TITLE]**

[Description immediately below]

**[REVISION QUESTIONS]**
