## 🌟 Vision & Objective

In the competitive landscape of software engineering, technical proficiency is only half the battle. This project bridges the gap between academic theory and real-world interview performance. By leveraging a **Luxury Notion aesthetic** and **Glassmorphism design principles**, it provides a distraction-free, elegant environment for mastering core engineering pillars.

## 🛠️ Tech Stack & Engineering Rationale

| Technology | Purpose | Rationale |

| **Vite** | Build Tool | Blazing fast HMR and optimized production bundles. |

## 🚀 Key Features

### 1. **Dynamic Learning Paths**
A centralized dashboard (`/prep-paths`) that allows users to choose specialized tracks: **Python Master**, **SQL Specialist**, **DSA Expert**, and **Cloud Architect**.

### 2. **Technical Deep Dives**
Interactive lessons covering:
- **Four Pillars of OOP**: Inheritance, Encapsulation, Abstraction, and Polymorphism with step-by-step logic.
- **Dunder Methods & Constructors**: Detailed analysis of `__init__` and `super()`.
- **Data Security**: Practical implementation of Private and Protected variables.

### 3. **Premium UX/UI**
- **Glassmorphism Design**: Soft champagne gold and ivory palette.
- **Responsive Architecture**: Fully optimized for mobile, tablet, and desktop viewing.
- **Live Search**: Efficient content discovery across the entire curriculum.

## ⚙️ Getting Started

### Prerequisites
- Node.js (v16.x or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/chintadavasudharini/InterviewPrep.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Launch the development server**
   ```bash
   npm run dev
   ```
